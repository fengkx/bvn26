# 死神 VS 火影 2.6：精简移植资料

用于将用户上传的普通 V 2.6 移植到 Godot。入口仍是上传的 `166.swf` 原始字节，在本目录命名为 `game/main.swf`。主程序为 600×400、30 FPS。本次未实现 Godot 版本，也未完成对战运行验证。

## Brx86/BVN2.6 仓库是否完整、能否替换？

检查固定提交：[f53f104](https://github.com/Brx86/BVN2.6/tree/f53f104d5b5b480c249fef4b33137c12c8d3a625)。

**就该仓库自身的改版而言，资源文件齐全；但它不是与上传文件相同的普通 2.6，不能整套替换原版移植基准。**

| 项目 | 用户上传版本 | 仓库版本 |
|---|---|---|
| 内部版本字段 | `V 2.6` | `V2.6 社长改` |
| 主程序帧率 | 30 FPS | 29 FPS |
| 主程序文件大小 | 约 8.44 MB | 约 37.53 MB |
| 人物配置条目，含援助/形态 | 64 | 69 |
| 主程序直接引用外部文件 | 74 | 87 |

仓库的 87 个外部引用都能在目录找到对应文件，但其中 **7 处大小写不一致**。在 Linux 等区分大小写的文件服务上，原样路径会找不到文件，除非服务端另外处理大小写：

| SWF 请求的文件 | 仓库实际文件 |
|---|---|
| `Byakuya.swf` | `byakuya.swf` |
| `Byakuya1.swf` | `byakuya1.swf` |
| `Kakashi.swf` | `kakashi.swf` |
| `Renji.swf` | `renji.swf` |
| `Sakura.swf` | `sakura.swf` |
| `Sasuke.swf` | `sasuke.swf` |
| `Sasuke1.swf` | `sasuke1.swf` |

路径均位于仓库 `static/fighter/` 下。带 `1`、`2` 后缀的 13 个 SWF 都被改版配置引用，用于独立形态，不能仅凭文件名相似删除。该改版的全部 SWF/MP3 都有入口或配置用途。

与上一轮补齐的普通 2.6 资源逐文件比较：

- 25 个文件字节完全一致，现已采用经过 Git blob 校验的仓库文件作为来源。
- 49 个文件解压后仍不相同，其中包括全部 35 个角色 SWF；这些保留上一轮与用户入口匹配的资源，不混入改版。
- 仓库增加/拆分了若干形态，例如 `minren1.swf`、`minren2.swf`、`yihu1.swf` 和 `yihu2.swf`。普通版中的相应形态原本共用角色文件，由 `WKframe` 等配置选择。

这些结论来自文件和反编译脚本检查，不等同于逐角色实测。上一轮资源来自与用户主程序仅全屏设置不同的公开入口对应资源；未获取历史原作者发布包的外部文件校验值。

## 此前精简时保留的资料

| 目录/文件 | 内容 |
|---|---|
| `game/` | 75 个文件：主程序、35 个角色、26 个援助、13 段音乐 |
| `scripts/` | 62 个 JSON 文件，对应每个 SWF 的反编译脚本 |
| `tools/` | SWF 结构检查和资料完整性验证工具 |
| `manifest.json` | 文件校验值、来源、仓库差异、角色/地图配置及脚本索引 |
| `README.md` | 当时的审计说明；现已移入本文件 |

8,853 份原脚本已按所属 SWF 合并为 62 个 JSON；每段脚本的原帧/事件路径和 UTF-8 字节均保留，整理前后已逐段验证。示例：`scripts/fighter/minren.json` 中的 `scripts` 数组包含每个片段的 `path` 与 `source`。这些是移植参考数据，不是已转换的 Godot 代码。

删除了重复的公开入口副本、主程序 PNG/JPEG/MP3 导出副本、重复统计和零散清单。原始 SWF 已保留，图片、声音和时间轴仍可重新提取。仓库的 Flask、Ruffle、WASM、source map 和旧网页包装不属于这个 Godot 移植资料包。

## 验证

在本目录执行：

```bash
python3 tools/verify.py
```

它检查文件 SHA-256、74 项资源引用的精确大小写、62 个 SWF 的结构及脚本关联。不会执行 Flash，也不能代替实际对战验证。

原上传文件 SHA-256：

`707fac0ec6bb2af1a3d18dc308dd403cb556a0988144b0f6f10555382287f92d`

反编译工具为 JPEXS 26.2.1。后续移植建议从鸣人、一护和一张地图开始，共用战斗核心沿用 30 Hz 主逻辑，并对照原时间轴、受击判定和计时行为。
