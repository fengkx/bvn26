# Production roster-open Web export

This local export opens Byakuya and Lee base-form fighter cards in the production selector. It preserves the original 40 fighter and 26 helper card layouts, along with the 9 existing fighters and 4 helpers.

Built with `tools/build_web.sh` (Godot 4.7.2). `dist/web/index.pck` is recorded by SHA-256 in `build-metadata.json`. The native production menu smoke passed for both candidates through VsHuman mode 3, normal source-card input, helper/map confirmation, and natural intro to battle. The smoke is not a browser UI test or original-player parity proof. No deployment was performed.
