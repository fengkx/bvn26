## Open findings

### P1 — Hurt movement and stun time advance during super freeze

`godot/fighter_runtime.gd` handles hurt actions before its `root_zhanting`
return. `_update_hurt_motion()` has no equivalent freeze guard.
Source: `scripts/fighter/minren.json`,
`DefineSprite_764/frame_1/DoAction.as`, `beidax(flying)` returns on
`_root.zhanting == true` before movement and `time++`.

Reproduction: receive the compiled Naruto `cbs2` attack, apply `cbsd`, then
call the defender's `enter_frame({})`. With `root_zhanting=true` and `hited=1`,
position changes from `(0, 0)` to `(20, -10)` and hurt time changes from 0 to 1.
The source invariant is unchanged movement and hurt time; stopping all hurt
playheads is not a valid substitute because `stopMc` intentionally skips them.

### P1 — Frozen helper hitboxes still deal damage

`godot/combat_resolver.gd::resolve_helpers` lacks the defender's
`_game_running()` gate used by `resolve_pair`. Stopping the helper's timeline
does not remove its active hitbox.
Source: `scripts/fighter/minren.json`,
`DefineSprite_2/frame_1/DoAction.as`, `checkHit()` returns before both fighter
and helper lookup when `!gameRunning()`.

Reproduction: activate the real Woailuo helper at source frame 44, overlap its
`atm1` and the defender's `bdmn`, apply `cbsd`, then run `resolve_helpers`.
The helper has `timeline_playing=false` and the defender has
`root_zhanting=true`, but HP changes from 1000 to 970.

## Follow-up resolution

Both P1 findings were fixed in the shared runtime paths on 2026-09-08:

- `FighterRuntime.enter_frame()` now preserves the source `beidax()` pause
  return before hurt movement and `time++`, without changing `stopMc` playhead
  eligibility.
- `CombatResolver.resolve_helpers()` now applies the defender's shared
  `gameRunning()` gate before sampling helper hitboxes.

The focused probe now exits 0 with unchanged hurt position/time and helper
damage `1000 -> 1000`. The same cases are also covered by `combat_smoke.gd`.
This resolves the two review findings only; it does not change the pending
M2-04 or original-player comparison status above.
